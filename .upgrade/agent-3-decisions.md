# Agent 3 — OpenZeppelin migration decision (2026-07-05)

## Choice

- **Single dependency: `@openzeppelin/contracts@5.6.1`** (latest audited release as of 2026-07-05).
- **Removed**: `@openzeppelin/contracts4` (4.9.6), `@openzeppelin/contracts47` (4.7.0).
- **Removed**: `@openzeppelin/contracts5` alias (replaced by direct `@openzeppelin/contracts`).

## Why

- The contract was originally split across three OZ v4 versions, which is a maintenance liability.
- v5 has been the stable line for 2+ years and contains audited 5.6.x releases.
- v4 reached end-of-life in early 2025 and no longer gets security backports.

### Source-level changes (also for Agent 8)

```solidity
// OLD:
constructor() Ownable() Pausable() {
  _grantRole(DEFAULT_ADMIN_ROLE, msg.sender);
  _grantRole(ADMIN_ROLE, msg.sender);
}

// NEW (v5):
constructor(address initialOwner) Ownable(initialOwner) Pausable() {
  _grantRole(DEFAULT_ADMIN_ROLE, msg.sender);
  _grantRole(ADMIN_ROLE, msg.sender);
}
```

The `using Address for address;` line and `using ReplayLibrary for ReplayLibrary.Transaction;` line remain valid in v5 (paths unchanged for the `using ... for` syntax — only the import paths are affected).
